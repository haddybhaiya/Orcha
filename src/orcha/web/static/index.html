Files and format

Keep the column headers, use ISO dates and three-letter currencies, and select all eight files together. Files may be header-only where appropriate. Up to 5 MB per file and 8 MB per request. Receipt images and PDFs are not supported by this upload.

A fresh view, every session.

Imports stay in memory on this computer. They are cleared when the server restarts. Your source CSVs are never changed. Set “Balance as of” to the date your imported balance was reconciled.

Where your data goes

Laya receives workflow flags only. Balances, transaction history, forecasts and verification stay in the local Python app. This workspace is for one person on this computer.
