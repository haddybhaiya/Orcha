# Orcha interface assets

All typefaces are self-hosted; the interface makes no external font or JavaScript requests.

- **Manrope**, copyright 2018 The Manrope Project Authors. Original variable font from https://github.com/google/fonts/tree/main/ofl/manrope, distributed under the SIL Open Font License 1.1. See `fonts/Manrope-OFL.txt`.
- **Newsreader**, copyright 2020 The Newsreader Project Authors. Original variable font from https://github.com/google/fonts/tree/main/ofl/newsreader, distributed under the SIL Open Font License 1.1. See `fonts/Newsreader-OFL.txt`.

The interface uses original HTML, CSS, SVG forecast lines and text symbols. No third-party component library or icon pack is included. Source font filenames: `Manrope[wght].ttf` and `Newsreader[opsz,wght].ttf`; their contents are unchanged, with simplified local filenames.
